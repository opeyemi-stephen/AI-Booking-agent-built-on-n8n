# AI-Booking-agent-built-on-n8n

Built an AI booking agent that handles Telegram text messages and voice notes. Groq Whisper transcribes voice notes, DeepSeek processes booking requests, and Airtable manages booking records.

### Booking Workflow
1. Receive text messages or voice notes through Telegram.
2. Transcribe voice notes using Groq Whisper.
3. Process requests using DeepSeek AI and conversation memory.
4. Check calendar availability using connected tools.
5. Collect booking details and create booking records in Airtable.
6. Send responses to users through Telegram.

**Tech stack:** n8n, Telegram, Groq Whisper, DeepSeek AI, Airtable, Simple Memory.
